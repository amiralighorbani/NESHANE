# تصاویر فروشگاهی «نشانه»

پوشهٔ تبلیغاتی برای مارکت‌پلیس‌ها: تصاویر آمادهٔ بارگذاری + متن فروشگاه + ابزار بازتولید.

```
marketing/
├── screenshots/       ۱۰ تصویر نهایی ۱۰۸۰×۱۹۲۰ (گوشی + متن تبلیغاتی)
├── shots/             اسکرین‌شات‌های خام خودِ اپ (۳۹۰×۸۴۴، دوبرابر = ۷۸۰×۱۶۸۸)
├── fonts/             فونت‌های خود اپ (برای متن روی تصاویر)
├── frames.html        بوم تبلیغاتی (منبع تصاویر؛ با `?i=۳` یک قاب را نشان می‌دهد)
├── gallery.html       بازبینی همهٔ تصاویر در یک صفحه
└── store-listing.md   متن فروشگاه: کوتاه، کامل، کلمات کلیدی و راهنمای تصاویر
```

## بازتولید تصاویر

تصاویر از **صفحه‌های واقعی اپ** ساخته می‌شوند (نه طرح دستی). کافی است سرور بالا باشد:

```bash
python -m uvicorn app.main:app --port 8020       # در یک ترمینال
python tools/make_store_shots.py                 # در ترمینال دیگر
```

اگر کروم جای دیگری است:

```bash
NESHANE_CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe" python tools/make_store_shots.py
```

### این اسکریپت چه می‌کند؟

۱. یک **کاربر نمایشی** می‌سازد (`neshane_demo` با نام «نیلوفر احمدی»، تهران، ۱۳۷۲/۴/۱۸).
۲. با نشست خودش سه خوانش (حافظ، تاروت، تاس) و یک تست کامل می‌سازد؛ پس تصاویر،
   دادهٔ واقعیِ خودِ موتور را نشان می‌دهند و هیچ متنی دستی جعل نشده است.
۳. HTML همان صفحه‌ها را ذخیره می‌کند، با یک سرور آینهٔ کوچک روی پورت ۸۰۹۹ (تا `/static`
   و فونت‌ها مثل خود اپ بالا بیایند) و کرومِ بی‌سر از هر صفحه اسکرین‌شات می‌گیرد.
۴. هر اسکرین را داخل ماکت گوشی می‌گذارد و با تیتر تبلیغاتی روی بوم ۱۰۸۰×۱۹۲۰ می‌نشاند.

### تغییر متن‌ها

متن تیتر/زیرتیتر و چیپ‌ها در `tools/make_store_shots.py` داخل `FRAME_COPY` و `CHIPS`
هستند؛ عوض کن و اسکریپت را دوباره اجرا کن. برای افزودن قاب تازه، یک سطر به
`FRAME_COPY` و `FRAME_SCREEN` اضافه کن (نامک باید با فایل اسکرین یکی باشد).

## نکته‌ها

- اسکرین‌شات‌ها با **موتور واقعی اپ** گرفته می‌شوند؛ پس اگر رابط تغییر کند، تصاویر را
  دوباره بساز تا با اپ هم‌خوان بمانند.
- دادهٔ کاربر نمایشی روی دیتابیس محلی می‌ماند؛ اگر لازم نیست، بعد از ساخت تصاویر
  می‌توانی از پنل ادمین پاکش کنی (کاربری با شمارهٔ ۰۹۱۲۰۰۰۰۰۷۷).
- تصاویر فعلاً برای «گوشی» هستند (نسبت ۹:۱۶). اگر برای تبلت یا دسکتاپ هم لازم داری،
  اندازهٔ پنجرهٔ کروم در اسکریپت (`SCREEN_W`, `SCREEN_H`) و اندازهٔ بوم
  (`CANVAS_W`, `CANVAS_H`) را عوض کن.
